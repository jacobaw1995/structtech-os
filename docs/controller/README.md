## THE RULE

**THE REPO IS THE ONLY SOURCE OF TRUTH. IF A DIRECTIVE CITES IT, IT LIVES HERE.**

The controller writes in the claude.ai project; Claude Code reads the repo. For three weeks
those were two universes, and it cost the build twice:

- **2026-09-24.** Track X grepped the repo for "G11" and for the dates 2026-09-25 and
  2026-10-18, found nothing, and correctly reported the directive's premise as unverifiable.
  The gates were real. They lived where no executor could read them. `docs/GATES.md` exists
  because of that.
- **2026-09-28.** The controller wrote the authoritative scope-sheet spec into the project and
  then handed all three tracks a directive that cited it. Same failure, four days later.

**A DEADLINE THE EXECUTOR CANNOT READ IS A DEADLINE THAT CANNOT BE CONTRADICTED** — and the
rule is broader than deadlines. Every directive on this build carries its denominators
*specifically* so CC can contradict them. A citation to a document CC cannot open is a
citation that cannot be checked, which makes it an assertion wearing evidence's clothes.

**So: anything a directive references is in this repo BEFORE the directive is issued, or the
reference is not made.** Not afterwards, not "I'll copy it over" — before.

---

## AND THE SOURCE GOES WITH THE SUMMARY

When the controller writes a spec from an artefact — a PDF, a screenshot, a transcript — the
**artefact ships too**. `docs/SCOPE_SHEET_SPEC.md` is the controller's *reading* of
`docs/reference/BMR_Job_Scope_Initial_Inspection.pdf`: the section count, the input count, the
gate logic are all the controller's, and all contradictable. With only the summary in the
repo, every error in the reading silently becomes the build.

**AN OBSERVATION AND ITS EXPLANATION ARE TWO FACTS, NOT ONE.** Six premises in one day's
directives were wrong on 2026-09-27, every one the same shape: a true thing Jacob saw, with
the controller's mechanism attached to it and stated at the same confidence. All six were
caught because they were stated. They are only catchable if the executor can reach the source.
